# ⚡ Getting Started

## Clone the repository

```bash
git clone https://github.com/AnneKay17/FUTURE_FS_01.git
```

## Navigate into the project

```bash
cd FUTURE_FS_01
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```
